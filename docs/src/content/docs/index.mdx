`@mmmike/web-push` is a TypeScript library for Web Push notifications. It generates the VAPID keys, subscribes the browser, and encrypts and sends each notification with `fetch` and Web Crypto, so the server code runs unchanged on Cloudflare Workers, Deno, Bun and Node 22.12+.

```bash
npm install @mmmike/web-push
```

```ts
import { sendPushNotification } from "@mmmike/web-push/send";

const delivered = await sendPushNotification(
	subscription,
	{ title: "New message", body: "Ada replied to your post", url: "/inbox" },
	{ publicKey, privateKey, subject: "mailto:you@example.com" },
);
if (!delivered) await store.delete(subscription.endpoint);
```

`publicKey` and `privateKey` are a VAPID key pair, which the [VAPID key generator](/generate-vapid-keys/) makes in your browser.
