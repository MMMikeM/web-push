## 1. Try it

<Row id="try-it">

This button subscribes your browser with the site's own VAPID key, then asks the Cloudflare Worker that serves these docs to send you one notification through this library. The Worker stores nothing.

## 2. The four pieces

<Row>

<PieceList section={2}>

1. [`/vapid`](/reference/vapid/) Generate your VAPID key pair once, on the server or in the browser.
2. [`sw.js`](/getting-started/#2-add-a-service-worker) A copy-paste service worker that shows the notification and handles the click.
3. [`/client`](/reference/client/) `subscribe()` resolves to subscribed, denied or unsupported.
4. [`/send`](/reference/send/) Send to one subscription, or fan out to a list. A gone subscription resolves `false`, so you know to delete it.

</PieceList>

<MarginNote slot="note">
	Each one tree-shakes on its own. The browser half is about 1.3 kB, the server
	half 3.6 kB, minified and gzipped.
</MarginNote>

</Row>

## 3. Runtimes

<Row>

If it has `fetch` and `crypto.subtle`, it works. No Node emulation, no polyfills, no compat layer.

<div class="chips">

- Node 22.12+
- Bun
- Deno
- Cloudflare Workers
- Vercel Edge
- Browsers

</div>

<MarginNote slot="note">
	Why 22.12? It's the first Node that can `require()` an ES module, so CommonJS
	projects can load this package too.
</MarginNote>

</Row>

## 4. Security considerations

<Row>

Payloads are encrypted with RFC 8291 `aes128gcm`, and every request is signed with RFC 8292 VAPID. The push service in the middle carries your message but can't read it.

<RelayDiagram />

<MarginNote slot="note">
	Push services return 201 even when the payload is broken, so you'd never know.
	Hence the RFC's own test vector, pinned byte for byte.
</MarginNote>

</Row>

<Row>

<mark>100% test coverage</mark>, and every release waits on conformance checks
in Node, Deno, Bun and Workers. Every push to the repository also delivers a
real notification through Chrome's and Firefox's push services.

<MarginNote slot="note">
	The first release had no tests at all. This is the apology.
</MarginNote>

</Row>

<Row>

Zero dependencies.

<MarginNote slot="note">
	On the build side: SHA-pinned Actions, npm provenance, and a seven-day wait
	before new dev-dependency releases are installed.
</MarginNote>

</Row>
